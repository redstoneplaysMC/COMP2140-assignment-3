# COMP2140-assignment-3
Assignment 3 for COMP2140: Mobile WebApp for the COMP2140 PresentLive application.

# Vision Statement
The chosen advanced features are:
Drawing over slides/ annotated decks.
Study Group: A few people sit together in a room with one presentation on multiple devices. A user can send everyone to a slide, 
highlight a part of it, or point to a detail, and other devices follow so the group's attention stays on the same thing.

Leadership passes around the group, and the annotations and questions each person adds appear on everyone's phone; building a 
shared record of the discussion.

Required Functionality:
App Design and navigation
A mobile-first experience.
At least 2 advanced functionalities.
A cohesive experience.
Data and Multiple users.
Mobile context, and error-states.
